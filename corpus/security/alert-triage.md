# Security Alert Triage Runbook

## First look
Check the alert source, the asset owner, and whether similar alerts fired recently.

## Enrich
Query identity logs, endpoint telemetry, and threat intelligence to decide whether the activity is expected.

## Decide
Close with a note if benign. Escalate to incident response if the activity touches credentials, privileged accounts, or sensitive data.
