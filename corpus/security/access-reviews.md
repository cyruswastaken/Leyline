# Quarterly Access Review Procedure

## Scope
System owners review who can access their systems every quarter, including service accounts.

## Process
Owners receive a list of users and roles, confirm or revoke each entry, and return it within ten working days.

## Follow-up
Security removes revoked access and reports overdue reviews to the director.
