# Requesting Software

## Approved catalogue
Common tools such as the office suite, browser, and chat client install from the Software Center without approval.

## New software
Submit a request in the service portal with the business reason. Security reviews the vendor and IT confirms licensing. Reviews normally take up to ten working days.

## Not allowed
Do not install software from unofficial sources or use personal licenses on company devices.
