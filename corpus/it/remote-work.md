# Working Remotely Securely

## Before you start
Use only company-managed laptops and keep the operating system updated. Connect to the corporate VPN before opening internal systems.

## Home network
Change the default router password and use WPA3 or WPA2 encryption. Do not use public computers for company work.

## Public places
Use a privacy screen in cafes and lock your screen whenever you step away.
